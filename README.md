# 本地相册

在手机上浏览已经保存在本机的照片和视频。界面用简体中文，字号和按钮都偏大，方便长辈点按。

这是一个独立的 Android 应用，不是网页套壳。它只读取本机媒体库，不连接任何网上相册，仓库里也不包含示例照片或视频。

## 用 Android Studio 打开

1. 安装 Android Studio（带 Android SDK 35）和 JDK 17 或更高版本。
2. 选择 **Open**，打开本项目根目录，等待 Gradle 同步完成。
3. 用真机或模拟器运行 `app`。

## 构建并安装调试包

```bash
./gradlew assembleDebug
```

请保留 `gradle.properties` 里的 `android.disallowKotlinSourceSets=false`。当前 Android Gradle 插件默认不允许 KSP 用旧方式登记生成代码，这项设置是为了让 Room 能编译。

调试 APK 在：

```text
app/build/outputs/apk/debug/app-debug.apk
```

安装到已连接的设备：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

单元测试：

```bash
./gradlew testDebugUnitTest
```

- `minSdk` 26
- `compileSdk` / `targetSdk` 35
- Kotlin、Jetpack Compose、Material 3、Gradle Kotlin DSL

## 权限

应用只在本地读取照片和视频：

- Android 13 及以上：`READ_MEDIA_IMAGES`、`READ_MEDIA_VIDEO`
- Android 14 及以上：可以选择只授权部分照片（`READ_MEDIA_VISUAL_USER_SELECTED`）。首页会提示「选择更多」
- Android 12 及以下：`READ_EXTERNAL_STORAGE`

如果拒绝授权，会看到中文说明，以及「允许访问」和「去设置」。相册为空时不会崩溃。应用不申请网络权限。

## 现在有的功能

- **首页相册列表**，可以一直往下翻，没有单独的「加载更多」按钮。
- **每个有照片或视频的月份都是独立相册**，标题如「2026年6月」。打开后只显示那一个月的内容，不会把月份合成一条时间线。没有日期的内容放在「日期未知」。
- **系统文件夹**，例如相机、截屏、微信，名称来自媒体库。常见英文文件夹名会显示成中文。
- **智能相册**（没有内容时不显示）：
  - 实况：本来就是实况照片或动态照片的条目
  - 视频：只含视频
  - 我喜欢的：点过「喜欢」的条目
  - 有留言：写过留言的条目
- **排序**：热度 = 该相册里「喜欢」的次数 + 留言条数。同一张照片若同时属于月份相册和文件夹，两边都会计入。热度大于 0 的相册排在前面，热度高的更靠上；热度为 0 的相册保持常规顺序：月份（新的在前）、文件夹（按名称）、智能相册（实况、视频、我喜欢的、有留言）。
- **相册网格**：照片和视频缩略图。视频有播放标记，能读到时长时一并显示。顶部是「返回」和相册名。
- **全屏查看**：1 倍时左右滑动切换。照片可双指缩放大约 1 倍到 4 倍；放大后单指移动画面，不会切到下一张。加载照片时背景是黑色，不用灰色占位块。视频使用 Media3 自带的播放控件。画面下方显示中文拍摄日期（例如「2026年6月15日」）。
- **喜欢**：每张照片和每个视频都可以点「喜欢」，保存在本机数据库里。放大照片时，喜欢按钮仍然留在画面下方。
- **留言**：可以查看和添加留言，同样只保存在本机。没有账号，也不会同步到别处。
- **播放实况**：只有文件本身已是实况照片或动态照片时才显示。播放结束后回到静止画面。普通照片不会出现这个按钮。

喜欢和留言保存在应用自己的数据库中。清除应用数据后会消失。

## 实况照片的范围

会识别这两类已经存在的实况内容：

- Android 动态照片：JPEG 或 HEIC 文件头里带有 Google `MotionPhoto` / 旧版 `MicroVideo` 标记，视频嵌在文件末尾
- 同一文件夹里、文件名相同的照片和短视频（例如 `IMG_100.jpg` 与 `IMG_100.MOV`），并且拍摄时间接近或视频很短（大约 5 秒以内）

不会用普通照片生成动态效果。只以专有格式嵌在一个文件里的 iOS 实况照片，如果看不出上述标记或配对文件，可能无法播放。这是当前版本的限制。

## 这个版本不做的事

应用锁、地点、自己新建或编辑相册、删除、分享、成长故事、设置页、账号、云同步，以及人脸或场景识别。
